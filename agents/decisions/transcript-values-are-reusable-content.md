# Transcript values are reusable content

A rendered line is not a message codec. Loom's Transcript retains the actual authored or
received Value under the original observation, bounded separately from display history and
outstanding asks. Workshop holds the terminal and answers its narrow capture door after the
same attributed gesture checks used by other acquisitions. The pane maps numbered wrapped rows
to instance/observation pairs and transports the resulting owned Inventory envelope.

The Inventory item remains pure message data. Separate metadata records the source instance,
observation, direction/address and observed answer provenance. These are historical observations,
not restored sender authority, routing instructions or a pending conversation. A copied command
requires an explicit target and current permission when invoked.

A second Workshop payload cache would split retention ownership. Reparsing prose or rerunning a
command would manufacture a different observation and possibly repeat effects. Both are rejected.
Missing/evicted entries refuse; the current 64 KiB copy carrier limit stays visible.
