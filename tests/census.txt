# The census: numbers the tree holds, each pinned by a row, read by tests/check_census.cmake, which
# is red where the tree and a row differ in either direction. A row marked `falls` may only fall: a
# change that raises one, or adds one, is red whatever else it says. A change that closes a reach
# lowers or removes its row in the same change, so a gain cannot be given back quietly.
#
# The line between Workshop and Zengine (agents/workshop-line.md). `side <folder>/ <side>`
# says whose a folder is, the longest that holds a file deciding; a file the package installs is
# the package's, and every other file is Zengine's. `line <file> <header> <count> falls` is a
# reach across it: a file of one side including, <count> times, a header of the other that the
# package does not install.
#
# What a file grows (agents/verification/checks.md, VM-CHECK-17), counted in the same code folders:
# `doors <file> <name> <count>` is the shapes one `loom::Accept<...>` list names, the list named by
# the class, struct or alias whose line opens nearest before it; `hooks <file> <struct> <count>`
# the `std::function` members of a struct a host hands a weave, from four on; `lines <file>
# <class> <count>` the lines of a class from 1000 on. A new door is a changed row where review
# sees it; a round that deletes lowers its row in the same change. The hub's doors, its host's
# hooks and every class's lines are marked to fall: a class past the threshold only shrinks, and
# one that falls below it loses its row.
#
# `cmake -DZEN_CENSUS_WRITE=<file> -P tests/check_census.cmake` writes the rows as the tree stands,
# to diff. ASCII only.
