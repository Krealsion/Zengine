# The values the code owns that a document or a comment has needed, read by `code_values`
# (tests/check_code_values.cmake; docs/contributing/repository-conventions.md#values-the-code-owns).
# A line registers one:
#
#   <id>  <owner file>  <symbol>
#
# The symbol is a `#define`, a constant (`S = v;`, `S{v}`) or a `set(S v)`. An id carrying `::`
# is the text's qualified spelling, for a name another file declares too. A value written without
# its owner's name is registered by how it is written, `{}` standing for the number:
#
#   claim   <id>  <spelling>   states the current value: every unmarked one is a copy
#   mention <id>  <spelling>   a copy at the current value unless it reads "since" or "and later"
#
# A shape's `Name vN` is an identity, frozen once published, and no copy of anything. When review
# finds a value copied that this file does not know, it is registered here then.
