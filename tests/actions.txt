# each, `<office> <mode> <id> <default key> <label>`, in the order the pane declares them. The key is
# spelled as a weaver's keymap file spells it, `unbound` for none; the mode is the census's own name
# for the state it drove the pane into. The census case in tests/test_workshop_panes_builder.cpp
# holds this file equal to what each pane declares and writes the census as it stands beside the
# build to diff; tests/check_manual.cmake holds every manual's commands and key markers to it.
# A pane is listed once a manual or a tutorial names its keys. ASCII only.
